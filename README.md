# Lina’s Homeworks

Сайт для публикации, отправки и ручной проверки домашних работ. Node.js 24+, SQLite и обычный HTML/CSS/JavaScript. Установка npm-пакетов не нужна.

## Структура проекта

| Путь | Что внутри |
| --- | --- |
| `src/server/` | HTTP API, правила валидации домашних работ и контракт JSON |
| `src/server/storage/` | Инициализация SQLite и схема таблиц |
| `src/web/` | Публичные страницы, кабинет ученика, админка и общие стили |
| `test/` | Интеграционные тесты и проверки формата заданий |
| `legacy/` | Исходный HTML-прототип для сравнения |
| `Dockerfile` и `compose.yaml` | Сборка и запуск приложения с постоянным томом |

## Запуск в Docker

Из папки с `compose.yaml` выполни:

```sh
cp .env.example .env
```

Впиши в `.env` свой пароль преподавателя длиной от 12 символов. Для просмотра на своём компьютере оставь `COOKIE_SECURE=0`.

```sh
docker compose up -d --build
```

Открой http://localhost:8080. Вход преподавателя находится по адресу http://localhost:8080/admin.

Для публичного запуска поставь перед приложением HTTPS-прокси, направленный на `127.0.0.1:8080`, и установи `COOKIE_SECURE=1`. У прокси должны сохраняться заголовок Host и возможность загрузки файлов до 20 МиБ. Используй один экземпляр приложения. SQLite и загруженные файлы сохраняются в томе `homework_data`. Для резервной копии останови сервис и сохрани весь том. Команда `docker compose down -v` удаляет данные.

## Работа с заданиями

В админке создай черновик вручную или вставь JSON. Там же можно скачать шаблон и JSON Schema. Для внешней LLM используй схему как формат ответа, вставь результат в редактор и проверь содержимое перед публикацией. Поля, неприменимые к типу вопроса, заполняются пустыми строками или массивами. У типов choice и multi должно быть не меньше двух вариантов. Для match нужны минимум две пары «текст ↔ картинка», для flash — минимум одна карточка. `solution` используется только для английского слова или фразы в виселице. Проверка и баллы всегда ручные.

После публикации отправь ученику ссылку на работу или её код. Ученик вводит только имя. После отправки ученик должен сохранить личную ссылку на результат. Любой, у кого есть эта ссылка, сможет открыть соответствующую оценку и комментарий. Изменение задания не меняет уже сданные работы. Архивирование закрывает новые отправки, сохраняя ответы и результаты.

Медиа можно загрузить в редакторе либо указать прямой HTTPS-адрес. Загруженные файлы открываются по своим адресам, поэтому не размещай там личные документы. Данные старого HTML хранились в браузере и не перенесены в SQLite автоматически.

## Разработка

```sh
ADMIN_PASSWORD='replace-for-local-use' COOKIE_SECURE=0 npm start
npm test
```

Тесты поднимают сервер с отдельной временной SQLite и проверяют публикацию, валидацию, авторизацию, отправку, ручную оценку, архивирование, медиа и сохранение данных после остановки сервера.
